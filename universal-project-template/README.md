# 通用项目协作模板

一套不绑定项目名称、语言、框架或平台的 AI 协作约定。保留任务管理、验证门、决策记录和开发日志；项目资料在导入后通过对话填写。

## 使用方式

1. 将本文件夹整体放到目标项目中，暂时不要覆盖项目根目录的同名文件。
2. 在目标项目启动 AI 对话，发送下面这段话（路径按实际位置调整）。
3. AI 先让你选择「新项目 / 已有项目」，再收集必要信息、生成或合并文档。

```text
请读取 universal-project-template/prompts/import-project.md，按其中流程将
universal-project-template/template/ 导入当前项目。先让我选择新项目还是已有项目，
项目名称、框架和技术架构通过对话确定；已有信息先从仓库提取。
```

这是文件模板和对话流程，不是自动安装器；复制文件夹不会自动运行、安装依赖或注册斜杠命令。

## 两种导入模式

| 模式 | 如何确定项目资料 | 首项工作 |
|---|---|---|
| 新项目 | 用户选择名称、目标、平台与技术偏好；不确定时先给候选方案 | F00 初始化运行基线 |
| 已有项目 | 先读取配置、入口、测试、现有约定；用户裁定不一致项 | 续接原任务，或新建基线盘点任务 |

已有项目保留任务编号、历史记录和本地修改。不要将 `template/` 直接整体覆盖到旧仓库。

## 约定

- `{{字段}}` 表示导入时替换的内容。未知项写「待确认」，不适用项写「N/A：原因」。
- 不预设四阶段、数据库、前后端分离或某套设计风格；CLI、库、数据项目也适用。
- 文档里所有「通过」必须来自实际验证。工具不可用意味着「未验证」，不等于 N/A。
- 看板采用便于复制维护的 Markdown。目标项目已有 `ROADMAP.html` 时沿用已有看板，并同步 AGENTS 中的路径，无需另建第二份事实源。
- 通用入口采用自然语言，不依赖某个 AI 工具。需要快捷命令时，再按目标工具的实际能力配置。
- 本目录是独立文档交付物，未修改来源项目的业务代码、任务状态和架构。
