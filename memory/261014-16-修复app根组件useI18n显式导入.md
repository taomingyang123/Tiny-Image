## 变更说明
1. **排查 app.vue 报 ReferenceError: useI18n is not defined 根因**：
   - 在开发模式运行期间，因全量构建命令或热重载重新生成 `.nuxt` 缓存目录时，Nuxt auto-import 虚拟模块的注入可能存在微小时序差。
   - `app.vue` 作为最顶层 Root 组件，在尚未完成动态 auto-import 注入前被浏览器执行，导致找不到全局 `useI18n` 抛出 `ReferenceError`。
2. **落地显式静态导入**：
   - 在 `app.vue` 中显式从 `vue-i18n` 导入 `useI18n`，从 `vue` 导入 `computed`。
   - 通过静态 import 确保打包器将依赖直接打包进入口 chunk，杜绝任何运行时的 auto-import 解析时序问题。
