## 变更说明
1. **Cloudflare Pages 安全响应头与严格零出站 CSP**：
   - 编写 `public/_headers`，配置全站防点击劫持（`X-Frame-Options: DENY`）、防 MIME 嗅探（`X-Content-Type-Options: nosniff`）、严格来源保护（`Referrer-Policy: strict-origin-when-cross-origin`）、全量 HTTPS 强校验（`Strict-Transport-Security`）与敏感硬件权限禁用（`Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=()`）。
   - 落地严格零出站流量 CSP 规则：`default-src 'self'; script-src 'self' 'unsafe-inline' 'wasm-unsafe-eval'; style-src 'self' 'unsafe-inline'; img-src 'self' blob: data:; worker-src 'self' blob:; connect-src 'self'; font-src 'self' data:; object-src 'none'; base-uri 'self'; form-action 'self'; frame-ancestors 'none';`，坚决锁定 `connect-src 'self'`，从浏览器安全协议层断绝任何图片向外发送的可能性。
   - 对 `/_nuxt/*` 静态资源与 `*.wasm` 资源配置长久强缓存（`Cache-Control: public, max-age=31536000, immutable`）与标准 MIME 类型。
2. **构建与门禁自动化联动**：
   - 更新 `scripts/build-public-files.mjs`，确保静态编译自动同步并输出 `.output/public/_headers`。
   - 更新 `scripts/seo-check.mjs`，在每次构建检查中强校验 `_headers` 文件及其 CSP 标头的完整性。
3. **文件名防穿越与危险注入防御**：
   - 强化 `lib/image/policy.ts` 中 `sanitizeFilename` 算法：先剥离原始扩展名并安全替换路径分隔符（`/`, `\`）与连续穿越点号（`..`），过滤 ASCII 控制字符与非打印字符，当且仅当输入完全由特殊符号组成时安全兜底为 `image`，杜绝路径穿越、空字节注入与畸形文件名。
4. **单元测试与网络隔离审计**：
   - 新增 `tests/unit/security.test.ts`（包含 11 项专门测试）：
     - 验证 `_headers` 与 CSP 规则的严密性；
     - 验证路径穿越（`../../../../etc/passwd`、`..\\..\\windows\\system32`）、控制字符、危险符号与批量稳定去重；
     - 挂载全局网络拦截器（Mock fetch / XMLHttpRequest），断言图片加入队列并完成全流程处理期间网络外发请求为 0。
