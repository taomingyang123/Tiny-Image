# T01-02 Codec 适配器与统一处理管线

## 背景

按照 `docs/02-ARCHITECTURE.md` 与 `docs/03-CONTRACTS.md`，构建 JPEG、PNG、WebP 的动态适配器，实现路径 A（PNG 无损二进制直接优化）、路径 B（JPEG/WebP 重编码）、透明背景填充白底与双线性降采样。

## 改动

- `lib/image/codec/jpeg.ts`：封装 `@jsquash/jpeg` `encode`/`decode`，严格限制 quality 为 1..100。
- `lib/image/codec/webp.ts`：封装 `@jsquash/webp` `encode`/`decode`。
- `lib/image/codec/png.ts`：封装 `@jsquash/oxipng` `optimise` 与 `@jsquash/png` `decode`。
- `lib/image/codec/alpha.ts`：实现 `flattenAlphaToWhite`，对输出 JPEG 的透明/半透明图像以纯白 (#FFFFFF) 背景合成，杜绝黑底。
- `lib/image/codec/resize.ts`：实现 `resizeImageData`，通过双线性插值纯算法实现平滑降采样，不依赖 DOM / Canvas，Worker 中无缝运行。
- `lib/image/codec/index.ts`：实现统一调度管线 `processImage`，根据策略路由到路径 A 或路径 B/C，逐阶段汇报进度 (`decode` -> `resize` -> `encode` -> `finalize`)。
- `tests/unit/codecs.test.ts`：针对各适配器与管线完成 6 项核心行为端到端测试。

## 验证

- 静态：`yarn typecheck` 0 错误。
- 运行时：`yarn test:unit` 全部 26 项单元测试通过。
- 系统级：`yarn generate` 构建成功，产物正确输出。
