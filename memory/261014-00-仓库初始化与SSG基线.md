# T00-01 仓库初始化与 SSG 基线核验

## 背景

用户提供 `CODEX_START_HERE.md` 明确本仓库作为独立图片压缩站 Tiny Image (`tinystool-image-tools`)，要求从阶段 0 启动（T00-01）。

## 改动

- 建立 Node 22 环境规范 `.nvmrc`。
- 更新 `package.json`：项目命名为 `tinystool-image-tools`，新增 `typecheck`、`test:unit`、`check` 脚本，引入 `vue-tsc` 与 `vitest`。
- 同步 Tiny Image 方案文档：复制 `docs/01-PRD.md` ~ `08-RISK-AND-DECISIONS.md`，启用 `.github/workflows/ci.yml`。
