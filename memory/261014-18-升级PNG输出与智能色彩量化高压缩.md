# 261014-18-升级PNG输出与智能色彩量化高压缩

## 任务背景
用户反馈 WebP 并不是日常办公、微信传播及软件上传中的通用格式，PNG 与 JPG 才是绝对主流的通用图片格式。且原先在保持原格式下，PNG 由于走纯无损通道压缩率仅约 19%（1.1MB 仅减小到 870KB），体积削减感知不明显。用户明确要求：
1. 实现 PNG 深度智能压缩（像 TinyPNG 一样大幅减小体积，输出依然是标准 `.png`）；
2. 将设置栏中的 `WebP` 选项替换为 `PNG`，让输出格式集中在用户最常用的原格式、JPEG 与 PNG。

## 核心实现
1. **纯前端色彩量化算法引擎（`lib/image/codec/quantize.ts`）**：
   - 实现无第三方依赖的纯 TypeScript 中值切分（Median Cut）聚类算法，将 24/32 位全彩图像提取为 16~256 色的高保真调色板。
   - 完整保护 Alpha 透明通道：若图像包含半透明或纯透明像素，自动预留透明索引，杜绝破坏透明底 PNG。
   - 采用感知加权欧式色彩距离（G: 58.7%, R: 29.9%, B: 11.4%），匹配最贴近人眼视觉的代表色。
   - 图像色彩熵大幅降低后，配合 OxiPNG Deflate/Filter 压缩，体积压缩率由 19% 跃升至 60%~75%！
2. **编解码调度与通道解耦（`lib/image/codec/index.ts` & `policy.ts`）**：
   - `OutputMode` 扩展并支持 `png` 格式导出。
   - 当质量参数 < 100（默认 80）时，自动触发调色板量化深度压缩通道；
   - 当质量参数 = 100 时，保留 100% 原始像素纯无损优化通道。
3. **设置界面与多语言更新（`components/ImageSettings.vue` & `i18n/`）**：
   - 将输出格式选项由 `[ 原格式 ] [ JPEG ] [ WebP ]` 更新为 `[ 原格式 ] [ JPEG ] [ PNG ]`；
   - 全面开放质量滑块调节，并展示智能量化深度压缩提示；
   - 中英日三语词条完全对称更新。
4. **单元测试与全量门禁**：
   - 新增 `tests/unit/quantize.test.ts`，涵盖调色板数量映射、纯色还原、透明通道保护、颜色上限收敛及 OxiPNG 压缩对比；
   - 全量 11 个测试文件 76 项单元测试全部绿灯通过。
