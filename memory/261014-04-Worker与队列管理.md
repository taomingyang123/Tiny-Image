# 执行日志：T01-03 Worker 与队列管理

- **日期**：2026-10-14
- **任务编号**：T01-03
- **任务目标**：实现生产级 Web Worker、Worker 客户端调度器与 Vue 客户端队列管理 Composable，支持单任务并发、超时强杀、取消与资源释放。

## 产出与变更

1. **`workers/image.worker.ts`**：
   - 监听 `WorkerRequest`（`PROCESS` / `PING`），调用核心管线 `processImage`。
   - 向上游上报阶段进度（`decode` -> `resize` -> `encode` -> `finalize`）。
   - 采用 Transferable ArrayBuffer 零内存拷贝回传压缩数据。
   - 实现细粒度异常分类映射（`PIXEL_LIMIT`、`DECODE_FAILED`、`WASM_LOAD_FAILED`、`OUT_OF_MEMORY` 等）。

2. **`lib/image/workerClient.ts`**：
   - 封装 Worker 实例生命周期管理（惰性加载、任务调度与异常监听）。
   - 强制并发数限制为 1，杜绝多任务并发争抢 CPU/内存导致的页面卡顿。
   - 实现 60s 默认超时强杀（`terminate()` 并抛出 `TIMEOUT` 错误）。
   - 实现主动取消协议：针对当前执行中任务直接终止 Worker 并触发 `CANCELLED`。

3. **`composables/useCompressionQueue.client.ts`**：
   - 基于 Vue 3 Composition API 构建客户端队列与状态机（`idle -> validating -> queued -> processing -> success/skipped/failed/cancelled`）。
   - 落地四重输入前置校验（0-byte `INVALID_FILE`、30MB 上限 `FILE_TOO_LARGE`、魔数识别 `UNSUPPORTED_FORMAT`、动图拦截 `ANIMATED_UNSUPPORTED`、32MP 像素超限 `PIXEL_LIMIT`）。
   - 每次处理从原始 `File` 重新读取字节，确保 Transferable 转移后依然支持无限次无损重试。
   - 实现精确的统计指标计算属性（节省字节、总体百分比、按状态计数）。
   - 严格管理 ObjectURL 内存生命周期，条目删除或清空时自动调用 `URL.revokeObjectURL`。

4. **`tests/unit/queue.test.ts`**：
   - 9 项高覆盖测试：涵盖消息协议流转、超时强杀、用户取消、空文件拦截、超大文件拦截、非图与动图拦截、队列顺序调度以及 ObjectURL 内存回收。

## 三层验证结果
