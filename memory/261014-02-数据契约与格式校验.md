# T01-01 数据契约与格式校验落地

## 背景

依据 `docs/03-CONTRACTS.md` 实现 Tiny Image 的核心数据结构、消息协议、文件魔数识别、动画检测与决策纯函数。

## 改动

- `lib/image/types.ts`：定义 `SupportedInput`, `SupportedOutput`, `OutputMode`, `CompressionOptions`, `CompressionStatus`, `CompressionErrorCode`, `CompressionResult`, `CompressionTask`, `WorkerRequest`, `WorkerResponse`。
- `lib/image/magic.ts`：通过文件头字节识别 JPEG (`FF D8 FF`)、PNG (`89 50 4E 47...`)、WebP (`RIFF....WEBP`)；解析 PNG chunk 识别 APNG (`acTL`) 动图；解析 WebP 识别 VP8X 动图标志位与 `ANIM` 动图。
- `lib/image/dimensions.ts`：实现快速文件头尺寸探测（无需解码全图）与像素安全阈值上限校验（32 MP / 16 MP）。
- `lib/image/policy.ts`：实现输出格式映射、PNG 无损优化路径判断、节省体积百分比计算、等比缩小（绝不放大）、文件名安全清理与稳定去重。
- `tests/unit/image-contracts.test.ts`：覆盖格式检测、动图拒绝、尺寸解析、政策计算等 17 项断言。

## 验证

- 静态：`yarn typecheck` 0 错误。
- 运行时：`yarn test:unit` 全部 20 项单元测试全绿。
- 系统级：严格杜绝信任用户文件扩展名；动画格式均有确定性拒绝凭据。
