# 2026-10-14 · 页面交互与响应式布局

## 任务背景与目标

对应任务 `T02-01`：实现 Tiny Image 核心页面交互组件与多端响应式布局，包括拖拽/剪贴板上传区、压缩与格式参数设置面板、文件任务列表、画质前后对比卷帘弹窗以及 ZIP/单张下载控制。

## 关键实现与改动

1. **拖拽与无障碍上传区 (`components/ImageDropzone.vue`)**：
   - 支持多文件拖拽拖放、点击触发选择原生 input。
   - 增加全局剪贴板图片粘贴（Ctrl+V / Cmd+V）自动解析并按 MIME 生成友好文件名。
   - 增加键盘无障碍：`tabindex="0"`、`role="button"`、Enter/Space 键触发选择、焦点高亮环。
2. **设置面板 (`components/ImageSettings.vue`)**：
   - 格式切换：原图保持（智能无损）、JPEG、WebP。
   - 质量滑杆：1~100 范围，推荐值 80，JPEG 白底提示，保持原格式时展示智能无损说明。
   - 最长边等比缩放预设：原尺寸、1920px、1280px 及自定义像素输入框。
3. **任务列表与状态卡片 (`components/ImageTaskList.vue`)**：
   - 队列状态统计：总数、已完成、累计节省体积与总节省百分比。
   - 任务卡片：展示原始缩略图、文件名、体积前后对比、节省比例、压缩阶段微状态（解码/缩放/编码/成功/跳过/失败/取消）。
   - 操作按钮组：前后对比查看、单张下载、取消正在处理、失败/取消重试、单项移除与一键清空。
   - 批量归档：一键打包下载为 ZIP（流式压缩无内存膨胀，带加载动画与错误横幅）。
4. **画质前后对比弹窗 (`components/ImageCompareModal.vue`)**：
   - 基于 `clip-path` 的卷帘分割器，支持鼠标拖拽与触控微调。
   - 键盘无障碍增强：支持 Escape 退出、左右方向键（ArrowLeft/ArrowRight）微调滑块位置、Home/End 键快速切换原图/压缩图对比。
   - 弹窗打开时自动锁定 `body` 滚动，支持快捷单张下载。
5. **深色主题与站点框架 (`app.vue`, `SiteHeader.vue`, `SiteFooter.vue`)**：
   - `app.vue` 在 `htmlAttrs` 中注入 `class: "dark"`，确保 Tailwind dark: 类在全站统一生效。
   - `SiteHeader.vue` 升级品牌 Logo 渐变图标，高亮当前语言与导航。
   - `package.json` 脚本注入 `XDG_CONFIG_HOME=.config`，确保 `yarn check` / `yarn generate` 在各种沙箱及 CI 环境中 0 报错执行。
