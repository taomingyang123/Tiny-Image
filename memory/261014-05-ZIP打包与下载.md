# 执行日志：T01-04 ZIP 打包与下载

- **日期**：2026-10-14
- **任务编号**：T01-04
- **任务目标**：实现单张图片下载、fflate 客户端流式 ZIP 打包、文件名清理与去重，以及移动端/客户端内存超限保护。

## 产出与变更

1. **引入轻量依赖 `fflate`**：
   - 纯 JavaScript、无 Node/WASM 外部依赖的微型压缩库（打包体积仅数 KB）。
   - 针对图片本身已高度压缩的特征，采用 `level: 0` 快速无损存储归档，极大降低客户端 CPU 消耗并杜绝 UI 线程卡顿。

2. **`lib/image/download.ts`**：
   - `downloadBlob(blob, filename)`：通过动态 `<a>` 标签触发安全本地下载，并在异步回调中自动回收 `URL.revokeObjectURL`，杜绝内存泄漏。
   - `downloadTask(task)`：自动适配单任务输出扩展名（JPEG 强制 `.jpg`，WebP 强制 `.webp`，PNG 保留 `.png`），提取优化后 Blob 或原图 Blob 触发下载。
   - `packZip(entries)`：多条目 ZIP 归档，集成 `deduplicateFilenames` 自动处理同名冲突（如 `img.jpg` -> `img-2.jpg`），防范路径穿越。
   - `downloadTasksAsZip(tasks, zipFilename, maxTotalBytes)`：支持过滤全部已完成任务批量导出 ZIP；默认设置 100 MiB 内存保护阈值（`DEFAULT_MAX_ZIP_BYTES`），避免超出移动端可用内存。

3. **`tests/unit/download.test.ts`**：
   - 5 项单元测试：通过 `unzipSync` 严格验证 ZIP 魔数签名（`PK\x03\x04`）、内容解压还原一致性、同名文件自动去重重命名、空输入保护以及超限拦截。
